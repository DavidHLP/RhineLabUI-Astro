# 安装、离线与更新

将模板部署到自己的 HTTPS 域名后，可通过浏览器菜单安装；iPhone / iPad 使用 Safari 的“分享 → 添加到主屏幕”。支持安装入口的浏览器也会在页面设置中显示“安装到设备”。

首次保持联网，等设置中的“主屏幕与离线”显示资源就绪后再断网。缓存包含首页、已发布文章、RSS、站点地图、字体、模型、音乐与 TXT；草稿不进入发行包。实际大小由构建输出报告。浏览器与主屏幕 App 可能使用独立存储，清除网站数据后需要重新准备缓存。

新版完整资源下载成功后，点击“更新并重启”。下载失败继续使用旧版；更新保留收藏与偏好。旧页找不到更新入口时，打开自己域名下的 `/update.html` 恢复，无需清空网站数据。

`npm run build` 生成静态页面与版本化 Service Worker，`npm run preview` 用于预览。开发模式不注册 Service Worker；正式构建只在 HTTPS 或 localhost 启用。缓存策略见部署说明。

减少动态效果首次跟随系统设置，也可在页面设置中选择完整、减少或自定义；保存的选择优先。声音需通过启动入口解锁，加载失败可重试或关闭声音进入。
