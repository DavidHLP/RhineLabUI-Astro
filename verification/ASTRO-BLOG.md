# Astro 博客模板迁移验证

## 范围

Astro 接管静态页面、Markdown 内容集合、文章路由、元数据、RSS、站点地图与构建。原生 Three.js 场景、模型、材质、镜头、开场、声音和响应式布局继续使用既有实现。40 份档案迁移为 Markdown 示例；`writing-a-post.md` 是不发布的写作示例。

文章数量允许变化，五列构图保留，每列至少一篇。正文进入原详情的概述页签，研究记录和 TXT 导出共用内容；编号继续作为收藏身份。直接打开文章、进入详情及浏览器前进后退同步地址和选档。

## 远端验证

环境：remote-dev、Node.js 22.23.3。生产代码提交 `ee87c23a43086fa0c0c1980316ca3d6290adef05`：

- `npm ci` 成功，依赖审计报告 0 个漏洞。
- `npm run build:cloudflare` 成功；Astro 检查 0 errors、0 warnings，1 个既有 `navigator.platform` 弃用提示；生成 42 个页面（首页、40 篇文章、404），另有 RSS 和站点地图。
- PWA 发行包 862 个文件，36.3 MiB；Cloudflare 包 867 个文件，已存在的许可字体通过校验。模板没有许可字体时使用原固定字形；原官方网站仍要求完整许可字体。
- `npm run check:content` 的 20 项检查通过；内容、稳定编号、分类、TXT、中文及嵌套文章路径均包含在内。
- `npm run check:viewport` 通过；Astro 模板可被已配置的 Prettier 插件解析。

随后扩展同一内容检查文件，用实际 Service Worker 源码验证离线首页、带／不带尾斜杠的文章地址以及 RSS 的缓存命中；此检查禁止网络回退。最终提交的运行结果见对应 PR 的 CI。

## 使用边界

先将 `content/site.json` 的 `site` 从 `https://example.com` 改为部署域名。示例发布日期是模板数据，不是原文真实发布日期。

每个页面预载所有已发布正文，以保持原阵列即时切档；适合当前规模的个人博客。文章集合显著增大时，可按需请求正文。既有 Three.js 客户端包仍有大于 500 kB 的构建提示，本次没有以删减画质消除该提示。

本次交付目标是 `DavidHLP/RhineLabUI-Astro`，不修改原作者仓库、正式网站或 DNS；历史参考、Blender 源文件、许可与署名保留。
